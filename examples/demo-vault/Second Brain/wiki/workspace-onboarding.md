Workspace onboarding is the shared path for configuring the app, setting
`VAULT_PATH`, scaffolding `Second Brain/`, and verifying that the backend and
frontend are connected.

## Local setup

Run `npm run setup`, configure `VAULT_PATH`, run `npm run setup:vault`, then start
the app with `npm run dev:all`.
